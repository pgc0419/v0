# v0 · 인천시청역 교통약자 안내

무경계 팀 · 2026 인천지역 공기업 ESG 아이디어 공모전 시범 앱입니다. 인천교통공사 공식 서비스가 아닙니다.

역 곳곳의 QR을 찍으면 지금 위치에서 시작하는 안내가 열리고,
역무원이 확인한 엘리베이터 상태와 확인 시각, 고장일 때 돌아가는 길, 휠체어 승차 위치, 역무실 바로 전화를 보여줍니다.

## 화면
- **홈**: 지금 위치(QR), 오늘의 엘리베이터, 즐겨찾는 길, 메뉴
- **즐겨찾는 길**: 자주 다니는 길을 저장하면, 그 길의 엘리베이터가 고장 났을 때 알림과 함께 다른 길(다른 출구 포함)로 안내 · 데모용 ‘고장 내기’ 버튼
- **엘리베이터를 쓸 수 있나요?**: 10대 상태 · 확인 시각 · 3시간 넘으면 경고 · 사용 불가일 때 돌아가는 길 · 고장 알림 받기
- **휠체어로 열차 타기**: 전용공간 칸, 안전발판, 갈아탈 때 내릴 칸·탈 칸
- **역무원 도움 요청**: 역무실·교통약자이동지원센터 바로 전화, 전화할 때 말할 문장
- **이동 경로**: 지금 위치에서 승강장·출구까지 (휠체어·유모차 / 계단 없이 / 빠른 길), 멈춘 엘리베이터는 빼고 안내
- **역 편의시설 · 역 밖으로 · 의견 남기기**
- **역무원 입력 화면(시험용)**: 상태 저장, 위치 QR 만들기·인쇄
- **글자 크게 · 소리로 듣기**

시범 버전이라 역무원 입력, 즐겨찾기, 의견은 그 폰에만 저장돼요.

## 정보 고치기 (현장조사 후)
`station.js` 한 파일만 고치면 됩니다. 항목마다 `src`가 화면 태그가 돼요.

| src | 화면 태그 |
|---|---|
| `site` | 공사 홈페이지 |
| `confirm` | 공사 확인 |
| `pub` | 공공데이터 |
| `todo` | 현장 확인 예정 |
| `ex` | 예시 |

예) 1호기가 석바위시장 방면 승강장과 이어진다고 확인했으면
`links: [["CONC", "P2S"]]` 로 바꾸고 `note`를 지우면 돼요.
